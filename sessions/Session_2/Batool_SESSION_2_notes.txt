The paper has improved a classical concept related to machine learning. It states that complex models do overfit but after a certain threshold the overfitting decreases, returning back to the optimal behavior. The evidence is provided by explaining the observed double decent curve. 
The goal of machine learning is to find a predictor or the hypothesis (hn) that produces the minimum empirical risk but also the minimum test error. Few terms to consider are hypothesis, function class (H), Empirical Risk Minimization (ERM). The function class is the collection of all the models that can be used to make the predictions but we choose the one hn based on the empirical risk. Empirical risk is the average loss value of a certain predictor from the H. In case of overfitting, the test error shoots up even if the empirical risk is too. But the classical belief is that maintaining the model capacity can avoid overfitting. Model capacity is the ability of predictors in H to represent more patterns in data. It can be increased in different ways but for this paper they have increased it by increasing the number of parameters or features. We can call it increasing the complexity. The belief is that at a certain capacity the model achieves a bias-variance trade-off where it neither overfits nor underfits. At lower capacity, it underfits and higher capacity then that it overfits. But the paper identified that increasing the capacity beyond the interpolation point (the point where overfit is max at some capacity) decreases the overfitting. 
The paper will provide evidence using neural networks and decision trees.
They used RFF with n data examples and N number of features. So the function class here has N complex parameters or 2N if real and imaginary are taken separately.
Initially, N < n so the model performs poorly when N is too small and overfits when N is close to n. But at interpolation threshold N = n, the model overfits really badly and the testing accuracy drops. When N > n, the model starts regaining the performance. But here is a catch. When rank is N, there was a unique minimizer that we used to make predictions but when N > n, there are non unique minimizers. Means multiple hypothesis will be producing the same least empirical risk. Therefore, we need l2 norm that selects the minimizer with the least magnitude of the coefficients of parameters. As N tends to infinity the testing accuracy reaches the maximum.
