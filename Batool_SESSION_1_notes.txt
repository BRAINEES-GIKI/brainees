The problem addressed by the paper is that we still do not know what controls the generalization error in deep learning models. The common believes hold by people are regularization and the type of model. This paper dismissed these common believes and the existing theory.

Firstly, a randomization test was conducted in which the true labels in the sample data were replaced by the random labels. As a result, the training error stayed 0 but the test error reduced because the actual labels weren't predicted. The behavior on test data makes sense because due to the random labels in training data, the model has not learned the meaningful information. While training, it learned from meaningful details and predicted the random labels correctly due to which it achieved the zero training error. The generalization error however increased to the difference in train and test error. 
They applied the same test on the images. This time instead simply changing the labels, they kept increasing the noise in true images. As the noise increased, the generalization error increased but the performance on the training set stayed the best. This suggests that model learns wrong stuff due to randomization but it still learns.
Also, they have used only images as a dataset. They first randomized the labels and then they did the same test by randomizing and changing pixels in different ways. The results were shown through different graphs which conclude that: as the steps increased, model starts overfitting. Randomized labels took more steps than the changed pixels. As the label corruption increased, models took more time to overfit or learn from meaningless data. As the label corruption reached 100%, the test error of all models reached to the maximum test error of 90% because minimum accuracy is 10%.
But what is proved by this randomization test?
Randmacher and VC dimension complexities explain the ability of neural networks to fit random patterns (or overfit) and to recognize the complex decision boundaries. They further build the idea of training performance in case randomization but they fail to explain the concept of generalization.
Now to defy the belief of explaining generalization through randomization, different models were tested on data with random and true labels separately with and without regularizers.There was no common pattern in the behavior. However, model performed really well without regularizers while testing on the data with true labels than on data with random labels. There should be a common behavior in both types of data without regularization if it explain generalization.

Later, the paper proposed a simple neural network for any sample of n rows and d features, giving us a total parameters equal to 2n+d
Firstly, n inputs are given to d neurons in layer 1. Then the output weight from each neuron is merged into a single weight in each of the n neurons in layer 2. These n weights give n weights to the neuron of output. Hence, d weights from layer 1, n from layer 2 and n from output. Giving us a total of 2n+d weights. 
In order to understand generalization, the paper tried to focus on the simplest linear models. If weights are greater than the sample size, then we can have a matrix with linearly independent columns. This can give us infinite weights and then we can predict any value using global minima (using ERM).
But there is still no explanation for the generalization due to global minima.
